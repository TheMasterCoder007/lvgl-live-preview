## Check your setup

LVGL Live Preview builds your C into WebAssembly with **Emscripten**.

**Requirements**

- **Python 3** on your `PATH` — needed both to install the toolchain and to run every build.
- **~1–2 GB** of free disk space for the toolchain.
- A network connection for the one-time toolchain and LVGL downloads.

Run **LVGL: Check Setup** at any time to verify these and see exactly what is missing.
